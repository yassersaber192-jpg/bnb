# أداة رفع الفواتير والإيصالات الإلكترونية

بتاخد ملف Excel وترفعه على منظومة الفاتورة الإلكترونية والإيصال الإلكتروني (مصلحة الضرائب المصرية) من غير ERP.

```
Excel  →  مراجعة وحساب الضرائب والإجماليات  →  توقيع بالتوكن (للفواتير)  →  رفع  →  تقرير Excel بالنتيجة
```

## اللي بتعمله

| | الفواتير (B2B) | الإيصالات (B2C) |
|---|---|---|
| الأنواع | فاتورة، إشعار دائن، إشعار مدين | بيع، مرتجع |
| الضرايب | قيمة مضافة (T1) + خصم تحت حساب الضريبة (T4) | قيمة مضافة (T1) |
| التوقيع | بالتوكن (CAdES-BES) | مش محتاج. الـ UUID بيتحسب أوتوماتيك |
| بعد الرفع | بتستنى نتيجة الفحص وتجيب سبب الرفض لو اترفضت | بتحفظ آخر UUID لكل نقطة بيع عشان التسلسل |

وفيها كمان:
- أكتر من شركة أو عميل في نفس ملف الإعدادات.
- كل الحسابات بـ Decimal ومقرّبة لـ 5 أرقام عشرية، زي ما المنظومة عايزة.
- وضع `--dry-run` بيراجع ويحسب من غير ما يرفع حاجة.
- كل مستند بيتحفظ JSON في فولدر `output` كأرشيف.

## التشغيل لأول مرة (على ويندوز)

1. نزّل Python 3.11 أو أحدث، وعلّم على "Add to PATH" وانت بتسطّبه.
2. افتح الفولدر ده واكتب:
   ```
   pip install -r requirements.txt
   ```
3. انسخ `config.example.json` باسم `config.json` واملا بيانات الشركة:
   - `rin`: رقم التسجيل الضريبي، و `activity_code`: كود النشاط، والعنوان.
   - `client_id` و `client_secret`: بتطلعهم من البوابة. ادخل على **إدارة الأنظمة (ERP)**، اعمل تسجيل نظام جديد، وسمّيه أي اسم.
   - `token_library`: مسار مكتبة التوكن، على حسب الشركة اللي طلّعته:
     - Egypt Trust: `C:\Windows\System32\eps2003csp11.dll`
     - MCDR أو SafeNet: `C:\Windows\System32\eTPKCS11.dll`
   - `pos`: نقط البيع بتاعة الإيصالات. كل نقطة ليها سيريال و Client ID و Secret خاصين بيها، ودول بيتسجّلوا على منظومة الإيصال.
   - `environment`: سيبه `preprod` (البيئة التجريبية) لحد ما تجرّب، وبعد كده غيّره لـ `prod`.

   > ملف `config.json` فيه بيانات سرية، وهو مستبعد من git. متبعتهوش لحد.

## الاستخدام

```bat
:: عمل قوالب Excel فاضية
run.bat template invoices فواتير.xlsx
run.bat template receipts ايصالات.xlsx

:: مراجعة من غير رفع
run.bat invoices فواتير.xlsx --company sample --dry-run

:: رفع الفواتير (هيطلب الـ PIN بتاع التوكن)
run.bat invoices فواتير.xlsx --company sample

:: رفع الإيصالات
run.bat receipts ايصالات.xlsx --company sample
```

### شكل ملف Excel
- **الصف الأول:** أسماء الأعمدة. متغيّرهاش.
- **الصف التاني:** شرح كل عمود بالعربي.
- **من الصف التالت:** البيانات. كل صف = صنف واحد.
- الأصناف اللي ليها نفس رقم الفاتورة (`internal_id`) أو نفس رقم الإيصال (`receipt_number`) بتتجمّع في مستند واحد، وبيانات العميل بتتاخد من أول صف.
- الأسعار بتتكتب **قبل الضريبة**، والأداة هي اللي بتحسب الضريبة.

النتيجة بتتحفظ في `output\اسم-الشركة\...\التقرير.xlsx`، وفيها حالة كل مستند (مقبول / مرفوض / خطأ في البيانات) والـ UUID وأسباب الرفض.

## لازم تبقى عارف
- **أكواد الأصناف** (EGS أو GS1) لازم تتسجّل وتتعتمد على المنظومة قبل أي رفع، وإلا الفاتورة هتترفض.
- **التوكن** لازم يبقى متركّب في الجهاز وقت رفع الفواتير. الإيصالات مش محتاجاه.
- **تسلسل الإيصالات:** كل إيصال فيه UUID الإيصال اللي قبله من نفس نقطة البيع. الأداة بتحفظ آخر واحد في `output\اسم-الشركة\receipt-chain.json`، فمتمسحش الملف ده.
- **التواريخ** بتتكتب بتوقيت القاهرة، والأداة بتحوّلها لـ UTC. التاريخ اللي في المستقبل بيترفض.
- **للتجربة من غير توكن على البيئة التجريبية** ممكن تستخدم `--pfx شهادة.pfx`.
